# Model assets

The FPS rifle and flying-enemy models in this directory were downloaded from
[Kenney's Starter Kit FPS](https://github.com/KenneyNL/Starter-Kit-FPS),
`models/blaster-repeater.glb` and `models/enemy-flying.glb`. The project README
identifies its 3D models as **CC0**. The original GLB files are retained here;
the centered OBJ files are converted copies used by AUTOMATA's OBJ loader.

- Upstream project: https://github.com/KenneyNL/Starter-Kit-FPS
- Asset license: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Conversion: `python examples/python/assets/models/convert_models.py`
- Conversion tool: `trimesh` (conversion-time only; not required to run the game)
