    Keyboard shortcuts

    Press F1 inside Oberon to see this list in the app. On macOS, Ctrl means ⌘.

    Everywhere#

    KeysAction
    Ctrl+NNew scene
    Ctrl+OOpen scene
    Ctrl+SSave scene (or the focused script)
    Ctrl+Shift+SSave scene as
    Ctrl+PPlay / Stop
    Ctrl+Shift+PCommand palette
    Ctrl+EGo to file (scripts by name, open ones first)
    Ctrl+Shift+BBuild the game (Exporting)
    Ctrl+,Settings
    Ctrl+= / Ctrl+− / Ctrl+0Interface zoom in / out / reset
    Ctrl+wheel over the code editorEditor zoom only (Settings › Script Editor › Editor scale)
    Ctrl+QQuit
    F1Keyboard shortcuts

    Scene#

    KeysAction
    ClickSelect
    Ctrl+click / Shift+clickAdd to or remove from the selection (Hierarchy: Shift+click selects a run)
    Shift+drag on empty spaceBox select (Editor workflow)
    Ctrl+ASelect everything
    Drag, right-drag, Alt+dragOrbit
    Middle-dragPan
    WheelZoom
    FFrame the selection
    W / E / RMove / Rotate / Scale gizmo
    Ctrl while dragging a gizmoFlip snapping for this drag
    ArrowsNudge the selection across the ground, relative to the view
    PgUp / PgDnNudge the selection up / down
    Shift + nudgeFine steps
    Ctrl+Z / Ctrl+YUndo / Redo
    Ctrl+C / Ctrl+VCopy / Paste the selection
    Ctrl+DDuplicate the selection
    Ctrl+Shift+DDuplicate Along a Line…
    DelDelete
    F2Rename
    EscDeselect

    File browser#

    KeysAction
    TypeFilter the list
    ↑ / ↓, PgUp / PgDn, Home / EndMove the highlight
    EnterOpen the folder / choose the file
    TabComplete the name
    Backspace (empty name) or Alt+↑Up one folder
    Alt+← / Alt+→Back / Forward
    F5Refresh
    EscClose

    Files panel (click it first)#

    KeysAction
    ↑ / ↓Select the previous / next file
    → / ←Expand / collapse
    EnterOpen
    F2Rename
    Ctrl+DDuplicate
    DelMove to Trash
    Ctrl+Shift+CCopy path

    Play mode (default player)#

    KeysAction
    W A S D or arrowsMove (relative to the camera)
    SpaceJump
    ShiftSprint

    Your scripts can read any key: ctx.input.pressed("q").

    Code editor#

    KeysAction
    Ctrl+SpaceComplete
    F12Go to definition
    Ctrl+F / Ctrl+HFind / Replace
    Ctrl+GGo to line
    Ctrl+/Toggle comment
    Ctrl+K Ctrl+C / Ctrl+K Ctrl+UComment / uncomment
    Ctrl+Shift+KDelete line
    Alt+↑ / Alt+↓Move line up / down
    Shift+Alt+↑ / Shift+Alt+↓Copy line up / down
    Ctrl+] / Ctrl+[Indent / outdent
    Ctrl+LSelect line
    Ctrl+Enter / Ctrl+Shift+EnterNew line below / above
    Ctrl+Shift+BackslashJump to the matching bracket
    Ctrl+↑ / Ctrl+↓Scroll without moving the caret
    EscDrop extra carets, then the selection, then leave the editor

    Multiple carets#

    Every caret types, deletes, pastes and completes at once, and one Ctrl+Z undoes the whole edit.

    KeysAction
    Ctrl+DSelect the word, then add the next match
    Ctrl+Shift+LSelect every match
    Alt+clickAdd or remove a caret
    Ctrl+Alt+↑ / Ctrl+Alt+↓Add a caret above / below
    Ctrl+C / Ctrl+X / Ctrl+VCopy / cut every selection; pasting as many lines as carets puts one line at each

    UI editor#

    Click the canvas or the widget tree first.

    KeysAction
    Delete / BackspaceDelete the selected widget
    Ctrl+DDuplicate it
    Ctrl+C / Ctrl+X / Ctrl+VCopy / cut / paste widgets
    ← → ↑ ↓ (Shift: by 10)Move a top-level widget by its margin
    Alt+↑ / Alt+↓Move it among its siblings
    Tab / Shift+TabSelect the next / previous widget
    EscSelect the screen
    Ctrl+Z / Ctrl+Y / Ctrl+SUndo / redo / save

    Tabs#

    These work from the Scene tab too. The Scene is always the first tab.

    KeysAction
    Ctrl+Tab / Ctrl+Shift+TabRecently used tabs. Hold Ctrl and press Tab again to go further back; release Ctrl to switch
    Ctrl+PgDn / Ctrl+PgUpNext / previous tab
    Alt+1 … Alt+9Go to tab by position (Alt+1 is the Scene)
    Alt+0Last tab
    Ctrl+Shift+PgDn / Ctrl+Shift+PgUpMove the tab right / left
    Ctrl+W / Ctrl+F4Close the tab
    Ctrl+Shift+TReopen the last closed tab
    Ctrl+K W / Ctrl+K UClose all / close saved tabs (unsaved tabs stay open)
    Ctrl+K SSave all

    With the mouse: middle-click a tab to close it, drag it to reorder it, and right-click it for Close Others, Close to the Right, Copy Path and Reveal in Files. The wheel scrolls the tab strip when tabs overflow.
