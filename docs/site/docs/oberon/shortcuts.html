    Keyboard shortcuts

    Press F1 inside Oberon to see this list in the app. On macOS, Ctrl means ⌘.

    Everywhere#

    KeysAction
    Ctrl+NNew scene
    Ctrl+OOpen scene
    Ctrl+SSave scene (or the focused script)
    Ctrl+Shift+SSave scene as
    Ctrl+PPlay / Stop
    Ctrl+Shift+PCommand palette
    Ctrl+,Settings
    Ctrl+= / Ctrl+− / Ctrl+0Interface zoom in / out / reset
    Ctrl+QQuit
    F1Keyboard shortcuts

    Scene#

    KeysAction
    ClickSelect
    Drag, right-drag, Alt+dragOrbit
    Middle-dragPan
    WheelZoom
    FFrame the selection
    W / E / RMove / Rotate / Scale gizmo
    ArrowsNudge the selection across the ground, relative to the view
    PgUp / PgDnNudge the selection up / down
    Shift + nudgeFine steps
    Ctrl+Z / Ctrl+YUndo / Redo
    Ctrl+C / Ctrl+VCopy / Paste entity
    Ctrl+DDuplicate
    DelDelete
    F2Rename
    EscDeselect

    Play mode (default player)#

    KeysAction
    W A S D or arrowsMove (relative to the camera)
    SpaceJump
    ShiftSprint

    Your scripts can read any key: ctx.input.pressed("q").

    Code editor#

    KeysAction
    Ctrl+SpaceComplete
    F12Go to definition
    Ctrl+F / Ctrl+HFind / Replace
    Ctrl+GGo to line
    Ctrl+/Toggle comment
    Ctrl+DDuplicate line
    Ctrl+Shift+KDelete line
    Alt+↑ / Alt+↓Move line up / down
    Ctrl+] / Ctrl+[Indent / outdent
    Ctrl+LSelect line
    Ctrl+EnterNew line below
    Ctrl+Tab / Ctrl+Shift+TabNext / previous tab
    Ctrl+WClose tab
    EscBack to the scene view
