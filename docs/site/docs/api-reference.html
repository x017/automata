    API Reference

    Every public name in the automata package. Conventions: angles are radians (Transform) or degrees (Camera3D.fov); colors are float tuples in 0.0..=1.0; Vec3 = tuple[float, float, float].

    import automata as at
at.__version__          # engine version string
at.Error                # engine runtime failure exception

    Game#

    at.Game(
    title="AUTOMATA",
    resolution=(1280, 720),
    headless=False,                     # no window/GPU; for tests and CI
    resizable=True,
    vsync=True,
    log_filter=None,                    # e.g. "debug"; RUST_LOG overrides
    target_fps=None,                    # int fps cap; None = engine default 60
    clear_color=None,                   # (r, g, b, a) window background
    graphics=None,                      # at.GraphicsQuality.HIGH etc.
    fixed_delta=None,                   # headless: every frame advances exactly this many seconds
)
    MemberTypeNotes
    run(update=None, max_frames=None) -> intmethoddrives the loop; returns frames run; a Game runs once
    load_scene(scene)methodreplaces the world: at once before run, at the end of the frame inside update or a handler
    quit()methodrequests shutdown
    steppingpropertyTrue while the browser drives the game frame by frame (web builds: run returns at once)
    on_finish(fn)methodcalls fn() when a web game ends (at once elsewhere): cleanup that would follow run
    stateproperty"created" / "running" / "shutdown"
    update(fn)decoratorregisters the per-frame callback
    on_event(name)decoratorregisters a handler for events named name

    OOP subclass hooks: on_start(), on_update(ctx), on_<event>(payload). Class attributes mirror every constructor option; kwargs win over them.

    Cameras#

    Visuals#

    at.MeshRenderer.cube(size=1.0, color=(1, 1, 1, 1))
at.MeshRenderer.sphere(size=1.0, color=(1, 1, 1, 1))  # size = diameter
at.MeshRenderer.quad(size=1.0, color=(1, 1, 1, 1))
at.MeshRenderer.model(path, color=(1, 1, 1, 1))   # .glb / .gltf / .obj
# every constructor also takes the keyword-only surface arguments:
#   roughness=None, metallic=None, emissive=(0, 0, 0), emissive_strength=1.0,
#   glow_light=1.0, glow_shadows=True
# and draw_distance=0.0 (metres; 0 = drawn at any distance)
# and material=None: a shared .mat.ron file that sets colour, surface and
#   textures (cube(material="materials/brick.mat.ron"))
m.kind                      # "cube", "sphere", "quad" or "model"
m.color                     # (r, g, b, a); tints a model
m.roughness                 # 0 = mirror .. 1 = chalk, or None (default)
m.metallic                  # 0 = plastic/wood/stone, 1 = metal, or None
m.emissive                  # (r, g, b) glow colour, (0, 0, 0) = none
m.emissive_strength         # glow multiplier
m.glow_light                # how much the glow lights its surroundings
m.glow_shadows              # whether objects block that light (HIGH and up)
m.draw_distance             # hidden past this camera distance, 0 = never
m.material                  # the material file's path, or None (own colour)
m.path                      # the model file, or None
m.bounds                    # ((min x, y, z), (max x, y, z)) or None

at.set_asset_root(path)     # where relative model paths resolve (None resets)
at.asset_root()             # the current root, or None

    Plain data; materialized on the GPU by the windowed driver, inert headless. Transform.scale sizes the primitive.

    Surface arguments: None roughness / metallic means "default", which is 0.6 / 0 for primitives and the file's own material values for models. Setting them overrides every part of a model. Roughness and metallic must be in 0..=1, and emissive values must not be negative, or ValueError is raised. A glowing mesh also lights the surfaces around it like a real glowing object of its size; glow_light scales that (0 = off). On HIGH and up, objects in the way block that light and cast shadows from it, unless glow_shadows=False. draw_distance hides the mesh, shadow included, when the camera is farther away than that many metres; it dithers out over the last tenth instead of popping. It must not be negative. Model files can also carry simpler levels of detail (Models). The glow added is emissive × emissive_strength; above 1 it blooms on Ultra and Beautiful. Guide: Rendering & Lights.

    material= names a material file (relative to the asset root, like model paths). It replaces the colour and surface arguments (and a model's own materials) and is read right away: a missing file raises FileNotFoundError; a broken one, or a path not ending in .mat.ron, raises ValueError.

    model loads the file right away, so a missing file raises FileNotFoundError and a broken one raises ValueError where you create the component. Relative paths resolve against the asset root. Scene.load / run_scene set the root to the scene's folder. If no root is set, the folder of the running script is used, then the working directory. The file is cached, so a thousand trees load it once. Guide: Models.

    DirectionalLight#

    at.DirectionalLight(direction=(-0.5, -1.0, -0.35),
                    color=(1.0, 1.0, 1.0), ambient=0.3, shadows=True,
                    *, shadow_distance=120.0, shadow_softness=1.0)

    The scene's sun; the first entity carrying one lights the frame. Getters: direction, color, ambient, shadows, shadow_distance, shadow_softness. Without one, a neutral shadowless default is used. shadow_distance (metres, above 0) is how far shadows reach; shorter is sharper. shadow_softness (0..8, default 1) is how soft their edges are. Out-of-range values raise ValueError. Guide: Rendering & Lights.

    PointLight / SpotLight#

    at.PointLight(color=(1.0, 0.85, 0.65), intensity=3.0, range=0.0,
              *, radius=0.05, shadows=True)
at.SpotLight(color=(1.0, 1.0, 1.0), intensity=8.0, outer_angle=30.0,
             inner_angle=None, range=0.0, *, radius=0.05, shadows=True)

    Placed lights. A PointLight shines every way from its entity's position. A SpotLight shines along its entity's forward axis (local −Z, turned by the entity's rotation). intensity 1 lights a surface 1 m away like a white sun overhead, falling off with the square of the distance. range (metres) ends the light; 0 works it out from the brightness. outer_angle is the cone's edge in degrees from its axis (0–80), and inner_angle is the full-strength core (default ¾ of outer_angle). radius is the size of the glowing source. shadows lets objects block the light (High and up, nearest first). Getters have the same names. Negative values, a zero radius, or angles out of range raise ValueError. Saved as point_light / spot_light in scene files. Guide: Rendering & Lights.

    Environment#

    at.Environment(sky_color=(1, 1, 1), ground_color=(1, 1, 1),
               background=(0.012, 0.012, 0.012), exposure=1.0,
               tonemapping="none", fog=False, fog_color=(0.5, 0.55, 0.6),
               fog_density=0.02, fog_start=0.0, sky=False,
               zenith_color=(0.16, 0.34, 0.78), sun_size=2.0, sun_glow=1.0,
               clouds=0.0, lens_flare=1.0, ambient_occlusion=1.0,
               fog_height=0.0, fog_falloff=0.0, fog_sun=0.0, god_rays=0.0,
               depth_of_field=0.0, focus_distance=0.0, focus_range=1.0,
               toon_bands=0, toon_softness=0.15, shadow_tint=(1, 1, 1),
               rim_light=0.0, painted_sky=False, outline=0.0,
               outline_color=(0.05, 0.04, 0.06), pixelate=0.0, palette=0,
               post=None, bloom=None, contrast=None, saturation=None,
               temperature=None, tint=None, lift=None, gamma=None, gain=None,
               vignette=None, grain=None, chromatic_aberration=None)
at.Environment.preset("neutral" | "daylight" | "dusk" | "night")
env.with_post(post=None, *, bloom=None, ...)   # same post keywords
at.Environment.post_presets()  # ["neutral", "bleached", "vivid", "film", "noir"]
at.Environment.style(name, base=None)   # "realistic", "semi-realistic", "botw", "a short hike", "nier"
env.with_style(name)
at.Environment.styles()        # the five names, in the editor's order
env.style_name                 # the style it is exactly, or "Custom"

    The scene look. The first entity carrying one wins. It sets hemisphere ambient (sky above, ground below, scaled by the sun's ambient), the background clear colour (overriding Game.clear_color), exposure, tone mapping ("none", "reinhard", "aces", "agx"), and exponential distance fog. sky=True draws a sky dome instead of the flat background: a gradient from background (the horizon) to zenith_color, a sun disk sun_size degrees wide where the scene's DirectionalLight shines from, a halo (sun_glow), clouds cover from 0 to 1, and on BEAUTIFUL a lens flare (lens_flare strength) when the camera looks toward the sun. Also on BEAUTIFUL, ambient_occlusion (0 off, 1 default, up to 2) darkens the ambient light in creases, corners and on the ground around objects. The non-neutral presets turn the sky on.

    Height fog: with fog_falloff above 0 the fog has full density below fog_height and thins by e every 1 / fog_falloff metres above it, so it lies in valleys. fog_sun (0..4) makes it glow toward the sun. On BEAUTIFUL, god_rays (0..2) draws sun shafts blocked by geometry, and depth_of_field (0..4) blurs what's nearer or farther than focus_distance ± focus_range metres (focus_distance=0 follows the camera's target). The "daylight" and "dusk" presets turn on height fog and god rays. See Atmosphere.

    Post effects grade the finished frame on MEDIUM and up: post starts from a named look, and the other post keywords change single fields on top of it (unset ones keep the look's value, or the neutral default without one). Fields are bloom (0..4, HIGH and up), contrast, saturation (0..3), temperature and tint (-1..1), lift, gamma and gain (RGB tuples), and vignette, grain and chromatic_aberration (0..1). with_post returns a copy with the post effects changed and everything else kept.

    Styles: Environment.style(name, base=None) applies a whole look to base (the default environment if omitted). It sets tone mapping, exposure, the lens, the height fog's shape, shading, outlines, pixels and post effects, and keeps the scene's colours, fog colour and density, sky and clouds. with_style does the same to a copy, and style_name reads back which style an environment is, or "Custom". The style's own fields: toon_bands (0..4 flat light steps, 0 = smooth) with toon_softness (0..1); shadow_tint, the colour of shade (RGB, white = none); rim_light (0..2); painted_sky (bool); and three screen effects for MEDIUM and up: outline (pixels on a 720 px screen, 0 = none) in outline_color, pixelate (pixel size on a 720 px screen, 0 = off) and palette (dithered levels per channel, 0 = full colour). See Styles.

    All arguments are readable as properties. Unknown tone mapping, preset, look or style names raise ValueError. It's saved in scene files. Guide: Rendering & Lights.

    Water#

    at.Water(size=(20, 20), deep_color=(0.01, 0.07, 0.11),
         shallow_color=(0.1, 0.42, 0.44), clarity=2.5, wave_height=0.12,
         wave_length=5.0, wave_speed=1.0, wave_direction=30.0, foam=0.6,
         density=2.0, drag=1.0, endless=False, caustics=1.0, wind=0.0)
at.Water.preset("pond" | "lake" | "ocean" | "sea" | "default")

    A rectangle of animated water on the entity's local XZ plane, size metres wide, centred on its Transform. Waves are Gerstner waves (wave_height crest to rest, wave_length of the main wave, travelling toward wave_direction degrees around +Y). Every quality preset draws it; BEAUTIFUL adds refraction of what's underneath, depth-based absorption (clarity is how many metres you can see down) and shoreline foam. endless=True (on the ocean and sea presets) continues the surface, flat and calm, out to the horizon; waves, foam and physics stay within size. caustics (0 to 2) is the strength of the light the waves focus on what's under them (Medium and up). wind (0 to 1) blows spray off the crests from 0.5 up (the Environment's wind too, whichever is stronger). With the camera under the surface the view fogs blue-green and the sound is muffled. It's also a volume of water for physics. Dynamic bodies in it float by buoyancy (density against their colliders' density, which defaults to 1.0, so a default box floats half under) and are slowed by drag. All arguments are readable as properties, and it's saved in scene files. Guides: Rendering & Lights, Physics.

    Grass#

    at.Grass(area=(0, 0), density=60.0, height=0.6, height_variation=0.45,
         width=0.07, base_color=(...), tip_color=(...), color_variation=0.3,
         draw_distance=60.0, seed=0)
grass.paint(position, radius=2.0, normal=(0, 1, 0), strength=1.0) -> Grass
grass.erase(position, radius=2.0, strength=1.0) -> Grass
grass.blade_count() -> int
grass.strokes  # how many brush strokes

    A field of blades over area (metres along the entity's X and Z, centred on it) plus brush strokes in the entity's space. paint and erase return changed copies. The blades sway in the Environment's wind, bend away from characters and moving bodies, and thin out toward draw_distance. Saved in scene files with its strokes. Guide: Grass & Foliage.

    Scatter#

    at.Scatter(area=(0, 0), density=0.2, scale=(0.7, 1.3), align=0.3, seed=0)
scatter.paint(...) / scatter.erase(...)  # as Grass
scatter.count() -> int

    Draws the entity's MeshRenderer at many spots on the ground instead of once (rocks, flowers, trees), each copy turned and sized at random between scale's ends and tilted toward the slope by align. Copies aren't solid. Guide: Grass & Foliage.

    ParticleEmitter#

    at.ParticleEmitter(**fields)                 # any field below by keyword
at.ParticleEmitter.preset("fire" | "smoke" | "sparks" | "dust" | "splash" | "magic" | "motes", **fields)
at.ParticleEmitter.presets() -> list[str]
emitter.replace(**fields) -> ParticleEmitter # a changed copy

    Fields (all readable as properties): emitting, rate, burst, duration, one_shot, max_particles, lifetime (min, max), shape ("point", "sphere", "box", "cone"), shape_size, cone_angle, speed (min, max), gravity, drag, size (birth, death), size_spread, color, color_end (RGBA, over 1 glows), fade_in, fade_out, spin, stretch, blend ("alpha", "additive"), lit, soft, sprite ("dot", "spark", "star", "flame", "puff"), texture, sheet (columns, rows), world_space, follow_camera (fill a box of shape_size around the camera, wrapping particles round as it moves). Pairs also take one number for both, and colours take RGB or RGBA. A bad name raises KeyError. A bad value raises ValueError. Saved in scene files. Guide: Rendering & Lights.

    Animation#

    at.Animation(clip="", speed=1.0, looping=True, play_on_start=True, root_motion=False)

    Plays a clip of the entity's animated model (a glTF with a skeleton or animated nodes on its MeshRenderer.model). clip is the clip played on start; "" shows the rest pose. speed is the playback rate (negative plays backwards). A clip with looping=False plays once and holds its last frame. root_motion=True lets the clip's travel across the ground move the entity (through its Character Controller if it has one) instead of sliding the model away from it. All five are readable properties. Saved in scene files. While the game runs, view.animation controls it (below). Guide: Models → Animation.

    Spring bones (hair, skirts and tails that swing on their own) aren't a component: they're set up in the model's import settings (<model>.import.ron), so every entity showing the model gets them. view.animation.springs says whether it has any, and view.animation.reset_springs() puts them back at rest. Guide: Models → Spring bones.

    Clips can also come from other glTF files made for the same skeleton, listed under clips in the model's import settings. A file with one clip names it after the file (anims/Run Fast.glb gives "Run Fast"); a file with several gives "file:Clip" ("sword:Slash"). They're in anim.clips and play like the model's own. Guide: Models → Clips from other files.

    Animation events are named moments in clips, set under events in the import settings ((clip: "Run", time: 0.18, name: "footstep")). A clip played once also fires "end". view.animation.recent_events lists the latest as (seq, clip, name), with seq counting up per entity. Behaviour scripts get them as on_animation_event calls and channel messages (below). Guide: Models → Animation events.

    Audio (ctx.audio)#

    Plays and controls sounds. Unlike scene/physics writes, audio operations apply immediately and queries observe live state — including within the frame that issued them. play returns an integer sound id used by the other methods. Volume is a linear amplitude (1.0 = full, 0.0 = silent).

    sid = ctx.audio.play("assets/jump.wav")          # -> sound id (int)
ctx.audio.play("assets/music.ogg", volume=0.6, loop_=True)
ctx.audio.play("assets/beep.wav", playback_rate=1.5, panning=-0.3)

ctx.audio.stop(sid, fade_out=0.2)                # fade out over 0.2 s, then stop
ctx.audio.stop_all(fade_out=0.0)                 # stop every sound
ctx.audio.pause(sid) / ctx.audio.resume(sid)
ctx.audio.seek_to(sid, 1.5)                      # seconds
ctx.audio.set_volume(sid, 0.8, fade=0.1)
ctx.audio.set_playback_rate(sid, 0.9)
ctx.audio.set_panning(sid, 0.5)                  # -1.0 left .. 1.0 right
ctx.audio.set_master_volume(0.7, fade=0.5)
ctx.audio.set_low_pass(800.0, fade=0.2)          # muffle everything (Hz)
ctx.audio.set_low_pass(None, fade=0.2)           # ... and clear it again

ctx.audio.is_playing(sid) -> bool
ctx.audio.position(sid) -> float | None          # seconds; None if unknown
ctx.audio.sound_count() -> int
ctx.audio.low_pass -> float | None               # the cutoff, or None if clear
ctx.audio.underwater -> bool                     # the camera's under water

    Supported formats: WAV, OGG/Vorbis, MP3, FLAC, PCM. A missing or undecodable file raises ValueError; an unknown sound id raises KeyError.

    Backend: the default build runs a silent backend — no audio device is touched, no sound is produced, but playback positions and states still advance deterministically, so headless runs and CI exercise identical code paths. Real device output requires the audio-cpal build feature (scripts/build.py enables it automatically when ALSA headers are present). If a device build finds no output device, it falls back to silent rather than failing.

    Behaviour scripts (automata.run_scene)#

    at.run_scene(path, *, max_frames=None, update=None, **game_options) -> int

    Plays an Oberon scene file with its behaviour scripts: start(entity, ctx), update(entity, ctx), stop(entity, ctx), and on_animation_event(entity, ctx, name) for the entity's own animation events, and on_joint_broken(entity, ctx) when its joint snaps. It returns the number of frames run.

    entity
    name, id, state (dict), grounded, script
    transformposition, rotation_euler (radians), scale; translate(d), rotate(d). Read, or assign
    character_velocitySet to move a character
    attributesDict-like, saved in the scene
    cameraScriptCamera or None
    audioplay(), stop(), playing, source
    animationplay(clip, loop=True, fade=0.0, speed=None, restart=False), stop(fade=0.0), clip, time (settable), duration, length(clip), playing, speed (settable), looping, clips, springs, reset_springs(), root_motion (settable), or None without an Animation. Reads include this frame's requests
    jointkind, connected (settable), value, angle, attached, broken, force, and settable enabled, motor_speed, motor_target, limits, break_force; or None without a Joint (Physics → Joints)
    camera_3dThe camera as a Camera3D (get/set)
    viewThe engine's EntityView for this frame
    despawn()At the end of the frame
    ctx
    timedelta, elapsed, frame (from 1)
    sceneScript entities: ["Name"], find, by_id, in, iteration
    inputKeys with the aliases "shift", "ctrl", "alt" (either side) and "left"/"right"/"up"/"down", or actions bound with settings.bind; axis(neg, pos); any_just_pressed() (the new key's name, for rebinding); mouse buttons, mouse_delta, lock_mouse; touches (fingers, or the left mouse button as finger 0); touch_controls (on-screen sticks and buttons: set(sticks, buttons, look, show), visible, stick(side), configured; see Touch controls)
    physicsgrounded, raycast, water_height(x, z); the rest of the engine's physics, which also accepts script entities
    waterheight(x, z) (same as physics.water_height), splash(position_or_entity, strength=1.0): rings and foam at that point (strength 0–10; 1 is about a crate dropped from a couple of metres)
    particlesburst(effect, position_or_entity, direction=None, count=None, **fields): a one-off effect (a preset name or at.ParticleEmitter, with fields changed) that cleans up after itself; emit(entity, count): extra particles from the entity's own emitter
    audio, hudOne-shot sounds; HUD images ("builtin:circle" and "builtin:ring" are built in), rectangles and text (hud.text(text, x, y, size=24, color, align, shadow, outline))
    cameraThe first Camera3D in the scene as a ScriptCamera
    events, resources, screen, raw, quit()Engine extras (run_scene only). screen.measure_text(text, size) gives text's pixel size
    subscribe(pattern, fn)Calls fn(msg) for each message on a matching channel: an exact name, or * and ? wildcards. Animation events arrive as "<entity>:animation:<event>". msg has channel, data, ctx, and for animation events entity, event and clip. Subscribing the same function again does nothing; the subscription ends with the subscribing entity. Returns a Subscription (cancel())
    unsubscribe(pattern, fn=None)Ends this script's subscriptions to pattern (or the Subscription passed); returns how many
    publish(channel, data=None)Delivers to every subscriber now; returns how many got it
    tween(entity, field, to, duration, ease="out_cubic", *, start=None, delay=0, loop=False, yoyo=False, on_update=None, on_done=None)Moves "position", "rotation", "scale", an attribute, or a key's component:field to to along an easing curve. loop=True repeats forever, loop=n plays n times; yoyo runs every other play backwards. A new tween on the same entity and field replaces the old. Returns a Tween: value, progress, done, cancel(), finish(), pause(), resume()
    tween_value(start, end, duration, on_update=None, ease="out_cubic", *, delay, loop, yoyo, on_done)A tween of your own value: read .value
    after(seconds, fn, *args), every(seconds, fn, *args, times=None)Calls fn(*args) once later, or every seconds. Returns a Timer: remaining, count, done, cancel(), pause(), resume(). Timers and tweens move before update, and end with the entity whose script made them
    saveA dict kept between runs as JSON (save["coins"] = 12): numbers, strings, booleans, None, lists and dicts. Written at the end of the frame if changed. Slots: use(slot), slot, slots() (SaveSlot: name, saved_at, keys), exists(slot), delete(slot), clear(), flush(), saved_at, path. Lives in .oberon/save while developing and in the user-data folder once exported (automata.script_api.user_data_dir(game); $AUTOMATA_SAVE_DIR overrides it). run_scene(save_dir=...) picks the folder
    settingsThe player's settings, saved and applied at start: volume (0–1, master volume), graphics (preset name), [name] for your own, reset(). Key bindings: bind(action, *keys) (defaults), rebind(action, *keys) (saved), keys(action), bindings(), reset_keys(action=None)
    ease(name, t)t through a curve: "linear", or in_/out_/in_out_ + sine, quad, cubic, quart, quint, expo, circ, back, elastic, bounce (automata.script_api.EASINGS)
    get(key), set(key, value)One exact key, entity:component:field. Components: animation (clip (setting it plays), time, speed, root_motion; read-only playing, looping, duration, clips, springs), transform (position, rotation, scale), attr (attributes by name). "Name:animation" gives the component, "Name" the entity. A shared name, a wildcard or a wrong key raises KeyError with a suggestion; read-only fields raise AttributeError
    scan(pattern), keys(pattern="*")Every value / key matching a * / ? pattern, in scene order, skipping entities without that component or field
    ref(key)A ComponentRef (used like the handle) or a FieldRef (.value, get(), set(v)) that looks the key up on each use; keep it from start
    log(...), warn(...)

    Reads see every write made earlier in the frame; writes apply after all scripts have run. That's the same model as Oberon's Play mode, from the same module (automata.script_api).

    ScriptCamera: position, target, fov (read/assign), look_at(point_or_entity), and follow(entity, offset=(0, 3, 8), smooth=8.0, look_height=0.6). Several writes in one frame accumulate. The same API exists in Oberon's Play mode. See Oberon: Cameras.
