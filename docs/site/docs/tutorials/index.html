    Tutorials

    These are hands-on walkthroughs, and each one ends with something that runs. Do them in order the first time; later tutorials assume the earlier ones.

    Oberon track#

    You build in the editor and write small Python behaviour scripts.

    TutorialYou'll learnTime
    Your first sceneCreating, moving, and lighting objects; a camera; Play; saving10 min
    Coin collectorBehaviour scripts, attributes, scoring, the Console, hot reload25 min
    Third-person cameraFollow, orbit, look-ahead, and sprint zoom with ctx.camera20 min
    Camera rail & intro shotKeyframed camera moves, easing, handing off to gameplay15 min
    Lighting & moodThe Graphics tab: sun, environment, tone mapping, fog, test scenes15 min
    From Oberon to Pythonat.run_scene, headless tests in CI, shipping a game15 min

    The finished project from these tutorials is in examples/oberon/coin_run/. Open level.ron in Oberon to compare with your own.

    Python track#

    You write games as plain Python programs, with no editor.

    TutorialYou'll learn
    Getting startedInstall, first window, first cube
    Zero to heroA complete platformer: scenes, input, physics, cameras, events, testing
    CookbookShort recipes: double jump, pause, spawn waves, screen shake
    Guide: CamerasFollow, orbit, rails, shake, zoom in code
    Guide: Rendering & LightsPrimitives, the sun, Environment, quality presets

    The two tracks meet: scenes made in Oberon load in Python (at.Scene.load), and scenes built in Python open in Oberon (scene.save("level.ron")).
